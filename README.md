# Favorite TV Show Website - Hawkins Survivors

A personal website built from scratch dedicated to my favorite show, Stranger Things. This project was created with love for the show and given to a very special friend.

## 🚀 Features
* **Home Page:** An introduction to the theme of Hawkins and the Gateway to the Upside Down.
* **Characters:** A dedicated section exploring the main survivors and characters from the show.
* **Lore & Quotes:** A collection of memorable quotes and background lore from the series.
* **Clean Navigation:** An easy-to-use navigation menu to seamlessly jump between pages.

## 🛠️ How I Made It
* **HTML5:** Used to build the structure and content of all the web pages (`index.html`, `characters.html`, `lore.html`, etc.).
* **CSS3:** Built custom styling from scratch to give the website a dark, atmospheric "Stranger Things" aesthetic.
* **Google Fonts:** Integrated the "Oswald" and "Rowdies" web fonts to match the show's retro vibe.
